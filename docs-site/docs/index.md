# Healthcare ML Genetic Predictor

Welcome to the documentation for the Healthcare ML Genetic Predictor project!

## Overview

This project is a real-time genetic risk prediction system built with:

- **Quarkus WebSockets** for real-time communication
- **Kafka** for event-driven architecture
- **KEDA** for auto-scaling capabilities
- **Azure Red Hat OpenShift** for deployment
- **Machine Learning** for genetic risk prediction

## Key Features

- Real-time genetic risk prediction via WebSockets
- Event-driven architecture with Kafka
- Scale-to-zero capabilities with KEDA
- Healthcare-grade security and compliance
- Containerized deployment on OpenShift
